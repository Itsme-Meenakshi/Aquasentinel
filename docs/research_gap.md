# Research gap

Published work documents the pufferfish problem in Kerala and maps *Lagocephalus* distribution from landings and GIS
(Mohamed et al., 2013; Saha et al., 2020). We found no open, reproducible workflow that takes haul-level presence/absence
records, tests simple predictive models against honest baselines on later data, and exposes the result in an auditable,
updatable monitoring tool. This project is a small pilot of that workflow on CMFRI haul data. (Literature search is not
exhaustive; extend `docs/literature_review.md` before claiming novelty.)
